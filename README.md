# Віджети для Notion

`index.html` / `saison.html` — сезонна анімація (осінь, зима, весна, літо) для вбудовування в Notion через /embed.
Без даних, без трекерів, без зовнішніх запитів. Параметри URL: `?season=automne|hiver|printemps|ete`, `?anim=0`.

## Інші файли
- `playlist.html?ids=<Apple ID через кому>&date=<дд.мм>&mood=<текст>` — плеєр «Ma playlist»: обкладинка, список, 30-секундні фрагменти з каталогу Apple Music, «↗» відкриває повний трек в Apple Music. Дані лише з публічного iTunes Lookup API, без ключів і без доступу до акаунта.
- `covers/{automne,hiver,printemps,ete}.gif` — анімовані сезонні обкладинки сторінок (фото: Unsplash).
- `cours/cours-1..6.png` — кольорові обкладинки карток курсів.
